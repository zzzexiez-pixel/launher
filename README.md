# MEOW Launcher

Качественный desktop-лаунчер для Minecraft на Python + PyQt5 с акцентом на масштабируемость, детализацию UX и архитектуру, близкую по духу к современным лаунчерам уровня Modrinth App.

## Что реализовано

- Современный интерфейс в стиле glassmorphism, безрамочное окно, кастомный titlebar.
- Экран авторизации:
  - логин/пароль;
  - опция «Запомнить меня»;
  - шифрование учетных данных через `cryptography.Fernet`.
- Модульная главная панель с разделами:
  - **Главная** — быстрый выбор режима (VANILLA/LITE/MODS), подготовка запуска, прогресс;
  - **Профили** — управление профилями (версии, лоадер, RAM, активация);
  - **Каталог модов** — поиск по Modrinth API;
  - **Логи** — журнал событий лаунчера в реальном времени;
  - **Настройки** — директория игры, RAM по умолчанию, проверка `JAVA_HOME`.
- Система профилей и настроек:
  - хранение в `~/.meow_launcher/settings.json`;
  - несколько пресетов «из коробки»;
  - сохранение и активация пользовательских профилей.
- Фоновая многопоточность (`QThreadPool` + `QRunnable`):
  - API-запросы;
  - подготовка файлов профиля;
  - статус и прогресс без блокировки UI.
- Генерация launch-конфига (`launch_args.json`) для каждого профиля.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Зависимости

См. `requirements.txt`:
- `PyQt5`
- `requests`
- `cryptography`
