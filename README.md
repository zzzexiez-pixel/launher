# MEOW Launcher

Minecraft-лаунчер на Python + PyQt5 с интерфейсом в стиле glassmorphism.

## Возможности

- Авторизация (логин/пароль) с чекбоксом **«Запомнить меня»**.
- Сохранение данных авторизации в зашифрованном виде (`cryptography.Fernet`).
- Главное окно с тремя режимами запуска:
  - **VANILLA** — чистая версия Minecraft.
  - **LITE** — профиль с оптимизационными модами (Sodium/Lithium/Phosphor).
  - **MODS** — профиль для Forge/Fabric и модпаков.
- Боковая панель настроек:
  - выбор директории игры;
  - выделение RAM через ползунок;
  - проверка переменной `JAVA_HOME`.
- Многопоточная загрузка файлов из интернета через `QThreadPool` + `QRunnable`.
- Прогресс-бар и текстовый статус загрузки.
- Для каждого режима создается отдельная папка внутри директории профилей.
- Безрамочное окно и кастомные кнопки закрытия/сворачивания.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
